# Revue juridique

Cette application fournit une information juridique.
Elle ne fournit pas une consultation juridique.

## Règles de validation

Chaque fiche juridique doit contenir :

- un identifiant unique ;
- un titre ;
- un résumé ;
- les acteurs concernés ;
- des mots-clés ;
- au moins une source officielle ou jurisprudentielle ;
- les articles applicables ;
- les conditions ;
- les effets ;
- un statut de revue.

## Sources prioritaires

1. Legifrance ;
2. Service-public.fr ;
3. Cour de cassation ;
4. Conseil d’État ;
5. EUR-Lex ;
6. Data.gouv.fr ;
7. Ministère de la Justice ;
8. Ministère de l’Intérieur ;
9. Sécurité routière ;
10. DGCCRF.

## Sources secondaires

- Dalloz, uniquement contenus accessibles légalement ;
- HAL ;
- OpenEdition ;
- Cairn gratuit ;
- Persée.

## Interdictions

- ne pas inventer un article ;
- ne pas inventer une décision ;
- ne pas présenter Dalloz comme source officielle ;
- ne pas affirmer une responsabilité judiciaire certaine ;
- ne pas utiliser des forums comme source juridique principale.

## Mention obligatoire

```text
Cette application fournit une information juridique à titre indicatif.
Elle ne constitue pas une consultation juridique et ne remplace pas un avocat.
```
